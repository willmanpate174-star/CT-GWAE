# Release contents

Original CT-GWAE numerical kernels, training budgets and seed schedules are retained. This public repository includes CT-GWAE training/inference, ablation/sensitivity/timing programs, 358 main-suite processed inputs and numerical reference results. Third-party baseline source copies and the processed DK/MNIST input arrays are not redistributed. See THIRD_PARTY.md and DATA_LICENSES.md for original sources and terms.

Paper publication identifiers will be added to CITATION.cff when assigned. The repository currently identifies the manuscript and its six authors without inventing a journal DOI or acceptance status.
